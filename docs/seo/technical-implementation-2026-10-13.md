# Техническое SEO/GEO при сохранении интерфейса

## Что установлено

У пяти существующих HTML-страниц сохранены уникальные Title/Description, canonical и структура заголовков. В sitemap входят только главная и конструктор. Юридические документы сохраняют noindex,follow. Семантическое ядро из 175 кандидатов и 15 тем статей находится в этой папке; частотность пока не измерена.

На главной добавлены семь сущностей Service, соответствующих существующим карточкам направлений: кухни, шкафы/гардеробные, спальни, детские, прихожие, мебель под лестницей и для ванной. Они связаны с организацией и списком услуг страницы. Названия и имеющиеся описания взяты из видимого текста карточек. Регион — только подтверждённый Липецк. Добавлены невидимые идентификаторы карточек для прямых ссылок.

Телефон, адрес салона, email, MAX и ежедневный график 09:00–19:00 в разметке организации сохранены. Цены, отзывы, рейтинги, лицензии изображений и неподтверждённые координаты не добавлены. Содержимое body сохранено байт-в-байт, кроме семи атрибутов id. CSS, фотографии, подписи, ссылки и обработчики не менялись.

## Подключение поисковых кабинетов

`tools/configure_search.py` устанавливает реальные коды подтверждения и обновляет адрес сайта в технических метаданных при переносе. По умолчанию показывает список изменений, ничего не записывая. Флаг `--apply` применяет изменения локально; затем нужен обычный push/deploy. Инструмент не обращается в кабинеты и не подтверждает владение автоматически.

Из Google Search Console нужен `content` из тега `google-site-verification`; из Яндекс Вебмастера — `content` из `yandex-verification`. Подставьте именно значения, полученные в своих кабинетах:

```bash
python tools/configure_search.py --google-verification "$SEARCH_GOOGLE_TOKEN" --yandex-verification "$SEARCH_YANDEX_TOKEN"
python tools/configure_search.py --google-verification "$SEARCH_GOOGLE_TOKEN" --yandex-verification "$SEARCH_YANDEX_TOKEN" --apply
```

Затем опубликуйте изменения, нажмите «Подтвердить» в кабинетах и отправьте sitemap. Коды подтверждения публичные; пароли и SMTP-ключи в репозиторий не записываются. Тесты допускают настоящие коды, но запрещают тестовые значения и дубликаты тегов.

Google: добавьте ресурс с префиксом URL `https://stas5252.github.io/mebelny-butik-48/`, выберите HTML-тег. Для окончательного собственного домена предпочтительнее подтверждение доменного ресурса через DNS.

Яндекс: для стабильного подключения нужен собственный домен. Тег в подкаталоге GitHub Pages не даёт контроль над корнем `stas5252.github.io`. Не подтверждайте чужой или недоступный корневой адрес. После получения собственного домена добавьте его в Вебмастер, подтвердите права и задайте регион Липецк.

При переносе на окончательный HTTPS-адрес:

```bash
python tools/configure_search.py --base-url "$SEARCH_SITE_URL"
python tools/configure_search.py --base-url "$SEARCH_SITE_URL" --apply
```

Меняются только head HTML-страниц, sitemap и robots; body, стили, тексты, фотографии и скрипты остаются прежними. Код не меняет дату lastmod при техническом переносе, не создаёт новые страницы и не меняет отправку заявок. На сервере отдельно нужны HTTPS, 301 с альтернативных адресов и robots.txt в корне домена. Для обновления хостингового ZIP используйте новые файлы из репозитория.

## Метрика и локальные карточки

Настоящий номер счётчика Метрики не предоставлен. Счётчик, Google Analytics, GTM и рекламные пиксели не включены. Search Console и Вебмастер работают без них. Перед включением аналитики нужно согласовать механизм выбора посетителя и актуальные документы об обработке данных. Если требуется новый видимый баннер, это отдельное изменение интерфейса; текущий запрет на его изменения сохраняется. Кнопка загрузки карты разрешает только карту и не является согласием на аналитику всего сайта.

Для Яндекс Бизнеса/Google Business Profile нужен доступ владельца: проверить существующие карточки, затем согласовать адрес, основной телефон, ссылку сайта и ежедневные часы 09:00–19:00. Публичная карточка Яндекса пока показывает в выходные 09:00–17:00 и дополнительный телефон, актуальность которого не подтверждена. Точку входа в салон должен проверить владелец. Доступа к карточкам сейчас нет, данные в них не изменены.

Для GEO в ответах ИИ использованы читаемый HTML и связанная разметка реальных услуг/организации. Особый файл llms.txt, выдуманные FAQ и гарантии попадания в ответы ИИ не нужны. Новые тексты и отдельные SEO-страницы не публиковались из-за запрета на изменение контента.

## Граница готовности

Установка тегов не равна подтверждению прав или индексации. Подключение кабинетов завершится после получения реальных кодов и подтверждения в них. Аналитика завершится после получения ID и настройки корректного выбора посетителя. Автоматическая отправка заявок требует PHP-хостинга и проверки доставки на mebelbutik.48@yandex.ru; GitHub Pages PHP не исполняет.

Скорость конструктора и его управление клавиатурой остаются отдельными задачами из полного аудита. Законодательные документы содержат ранее отмеченные незаполненные сведения. Эти пункты не устранены одной технической SEO-разметкой.

## Проверки этой редакции

Прошли 35 автоматических проверок: галерея, формы, конструктор, доступность ключевых сценариев, SEO и безопасная установка кодов/перенос адресов. После последних изменений инструмента повторно прошли его пять проверок и семь проверок SEO. Скриншоты семи карточек направлений совпали пиксельно на 390 и 1440 px после загрузки всех изображений. Видимый текст, высота документа и отсутствие переполнения также совпали. Отдельное сравнение пяти HTML-страниц подтвердило сохранность body и CSS; единственное исключение — семь невидимых идентификаторов карточек.
