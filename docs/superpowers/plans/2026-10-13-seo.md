# Техническое SEO без изменения дизайна и содержания

Уточнение заказчика: «Ты сам сайт не изменяй только технически». Новые страницы и статьи не публикуются. Видимые тексты, изображения и расположение блоков сохраняются.

1. Подготовить 175 кандидатов запросов, предложения по целевым страницам и 15 тем статей с Title, Description и структурой H1–H3 в документах для проверки. Предлагаемые адреса новых страниц явно обозначить как неопубликованные. Частотность без Wordstat не заявлять.
2. Для существующих пяти HTML-страниц настроить уникальные Title/Description, canonical, социальные метатеги. Сохранить noindex юридических документов и видимый текст всех заголовков. В интерфейсе конструктора заменить подписи существующих групп на семантические H2 с сохранением стилей.
3. Исправить техническую микроразметку главной: тип FurnitureStore, WebSite, WebPage, подтверждённый телефон/email/часы и MAX. Исключить неподтверждённые координаты и индекс. Добавить описание приложения и BreadcrumbList конструктора без обещаний расширенных результатов. Обновить sitemap и дату изменения; robots.txt пояснить с учётом корня GitHub Pages.
4. Проверить метатеги, JSON-LD, заголовки, sitemap и ссылки. Сравнить видимые тексты и скриншоты до/после. Запустить существующие браузерные проверки. Опубликовать только технические изменения и документы, проверить Pages и обновить архив для хостинга.

После выбора домена нужны подтверждение Вебмастера/Search Console, регион, Wordstat, отправка sitemap и мониторинг индексации. Эти внешние действия требуют доступа владельца.
